Security engineer. By day I break web applications, by night I write down how to fix them.

## Focus areas

- **Web application security** — access control, authentication flows, SSRF, injection, business logic.
- **Bug bounty** — recon pipelines, attack surface mapping, report writing.
- **Reverse engineering** — Android apps, native binaries, protocol analysis.
- **AI tooling for security** — agents, MCP servers, automation that replaces manual work.

## About this blog

This blog is organised as series, each series covering one area end to end instead of random one-off posts. The full list is on the [Series](/series/) page. Notes are written as I go: what I tried, what worked, what failed and why. Public bug bounty findings are only published after the report is closed.
